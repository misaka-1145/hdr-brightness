# HDR 内容亮度调节 · 使用说明

> 一句话：**把 Windows 那个「SDR 内容亮度」滑块拆成可以按显示器、按分组、按时间分别控制的版本。**

Windows 自带设置里只有一个全局滑块，所有 HDR 显示器共用同一个值。这个工具可以：

- 每台显示器单独调
- 几台捆绑成一组一起调（可保持亮度差）
- 到点自动调（例如工作日 08:00 → 100%，19:00 → 45%）

---

## 1. 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 1809 及以上 / Windows 11 |
| 显示器 | 需支持 HDR，并在「Windows 设置 → 系统 → 屏幕 → HDR」里**已开启** |
| 运行时 | .NET Framework 4.8（Win10 1809 以后系统自带，无需另外安装） |
| 权限 | **不需要管理员权限**（读写的是当前用户的配置和显示器状态） |

> 只有在显示器开启 HDR 时，这个亮度才会影响画面。没开 HDR 的显示器卡片上会显示「HDR 未开启」。

---

## 2. 第一次使用

1. 下载 `HdrBrightness.exe`，放到一个固定目录，例如 `D:\Tools\HdrBrightness\`（**放好后别再移动**，否则开机自启会失效）。
2. 双击运行。窗口打开后，每台显示器会显示为一张卡片。
3. 拖动卡片上的滑块即可立即生效。

首次运行会做三件事：

- 在系统里注册**开机自启**（可在「设置」里取消）
- 在 `%APPDATA%\HdrBrightness\settings.json` 建立配置文件
- 在右下角托盘区显示一个图标

> 程序没有数字签名，Windows SmartScreen 可能提示「Windows 已保护你的电脑」。
> 点「更多信息」→「仍要运行」即可；杀毒软件误报时把程序加入信任即可。

## 3. 界面导览

![主界面](../shot-group.png)

### 顶部按钮

| 按钮 | 作用 |
| --- | --- |
| 刷新 | 重新扫描显示器（插拔显示器、切换 HDR 后点一下） |
| 新建分组 | 建一个分组，用于把多台显示器捆绑在一起调 |
| 设置 | 开机自启、锁定亮度等选项 |
| 收起 | 把窗口收进托盘（不退出程序） |

### 卡片

- **全部显示器**：一次设置所有输出。
- **分组卡片**（紫色「分组」标记）：拖一次，组内所有显示器一起变。
  - 「同步」：组内所有显示器设成**同一个数值**
  - 「相对」：按**同样增量**调整，**保持彼此之间的亮度差**
  - 「解散」：删掉分组，显示器本身不受影响
- **显示器卡片**：
  - 左侧是型号和 HDR 状态（绿色=已开启）
  - 右上角下拉框选它属于哪个分组
  - 滑块下方的 `0 / 20 / 50 / 75 / 100` 是常用亮度按键，当前值正好等于某个档位时该按键会加粗
  - 最下面小字是接口名和内部原始值（排查问题时有用）
  - **双击显示器名字可以改昵称**（例如「主屏」「副屏」）

### 亮度含义

百分比与 Windows 设置里的滑块一致：**0% 最暗、100% 最亮**。
数值会被换算成系统的「SDR 白点值」（0% = 1000，100% = 6000），卡片下方小字里能看到。

## 4. 常见操作

**只调一台显示器**
→ 直接拖那台卡片上的滑块，或点它下面的常用按键。

**把两台/多台一起调**
→ 点「新建分组」→ 在每台显示器卡片右上角的下拉框里选择这个分组 → 之后拖分组卡片的滑块。

**在保持亮度差的前提下一起调**
→ 把分组模式切成「相对」，再拖分组滑块；两台差值会保持不变。

**一键到某个亮度**
→ 点卡片上的 `0 / 20 / 50 / 75 / 100`，或托盘图标右键 →「常用亮度」。

**让程序记住并自动恢复**
→ 保持「设置 → 锁定亮度」勾选。切换 HDR、休眠唤醒、重新插显示器后，程序会把亮度改回你设定的值。

**到点自动调**
→ 见下一节「定时规则」。

## 5. 定时规则

![定时规则](../shot-schedule.png)

界面底部「定时」区域 → 点「添加规则」，填写四项：

| 字段 | 说明 |
| --- | --- |
| 时间 | 24 小时制，例如 `08:00`、`19:30` |
| 重复 | 每天 / 工作日 / 周末 / 某个星期几 |
| 目标 | 全部显示器 / 某个分组 / 某一台显示器 |
| 亮度 | 百分比，可用滑块或常用按键 |

执行机制：

- 程序每 **20 秒**检查一次，到点即应用。
- 电脑睡眠或关机期间错过的规则，会在程序启动后**补执行一次**（回看最近 12 小时，取其中最后一条），
  所以开机自启后亮度会自动回到该有的状态。
- 规则写入配置文件，长期有效；显示器暂时没插上也不会丢，插回来照样生效。
- 每行左侧的勾选框可以**临时停用**某条规则（不用删除）；行尾有「修改」「删除」。
- 编辑窗口里的「立即应用一次」可以先试效果，确认后再保存。

一个典型配置：

| 时间 | 重复 | 目标 | 亮度 |
| --- | --- | --- | --- |
| 08:00 | 工作日 | 全部显示器 | 100% |
| 19:00 | 每天 | 分组「笔记本 + 外接屏」 | 45% |
| 23:30 | 周末 | 外接屏 | 20% |

## 6. 托盘菜单

右键托盘图标：

| 菜单项 | 作用 |
| --- | --- |
| 显示主窗口 | 重新打开窗口（双击图标也可以） |
| 刷新显示器 | 重新扫描显示输出 |
| 立即恢复亮度 | 立刻把亮度改回你设定的值 |
| 常用亮度 | 0 / 20 / 50 / 75 / 100 五个档位，作用于全部显示器；建过分组还会为每个分组各有一份 |
| 开机自启 | 勾选/取消开机自启 |
| 退出 | 完全退出程序（关窗口只是收进托盘） |

> 窗口右上角的「×」= 收进托盘，程序仍在后台按定时规则运行。要彻底退出请用托盘菜单的「退出」。

## 7. 设置项

| 选项 | 说明 | 建议 |
| --- | --- | --- |
| 开机自启 | 登录后自动在托盘运行 | 建议开启 |
| 手动启动时也直接进托盘 | 双击 exe 时不弹主窗口 | 一般不用勾 |
| 启动时恢复上次的亮度 | 启动时把上次的数值写回去 | 建议开启 |
| 锁定亮度 | 切 HDR、唤醒、重插显示器后自动改回设定值 | 建议开启；若你想用 Windows 设置里的滑块手动调，可关掉 |
| 检查间隔（秒） | 「锁定亮度」的检查周期，默认 20 秒 | 保持默认即可 |
| 打开配置文件夹 | 打开配置文件所在目录 | — |
| 全部设为 0% | 把所有显示器设为最暗档 | — |

## 8. 配置文件

位置：`%APPDATA%\HdrBrightness\settings.json`（在「设置」里点「打开配置文件夹」可直接打开）

主要字段：

| 字段 | 含义 |
| --- | --- |
| `Desired` | 每台显示器记住的目标亮度（内部原始值，1000–6000） |
| `Groups` | 分组定义与成员 |
| `Nicknames` | 显示器的自定义名字 |
| `Schedules` | 定时规则 |
| `LockBrightness` | 是否锁定亮度 |
| `AutoStart` | 是否开机自启 |

**备份/迁移**：直接复制这个 json 文件即可。
**重置**：删掉这个文件，下次启动会重新生成（分组、昵称、定时规则都会清空）。

> 调试时可以用环境变量 `HDRBRIGHTNESS_CONFIG_DIR` 指定另一个配置目录，程序不会碰默认位置。

## 9. 命令行工具（可选）

同目录下的 `hdrbright.exe` 可以脚本化调用：

```bat
hdrbright list                 列出所有活动显示输出、HDR 状态和当前亮度
hdrbright get 1                读取 1 号显示器
hdrbright set 1 75             把 1 号显示器设为 75%
hdrbright set all 100          全部设为 100%
hdrbright set 2 raw:3000       直接写系统原始值（1000 = 0%，6000 = 100%）
hdrbright debug                打印底层调用过程（排查问题时用）
```

`<目标>` 可以是 `list` 里的序号、`all`，或显示器名称的一部分。

## 10. 常见问题

**拖了滑块但画面没变化？**
1. 这台显示器可能没开 HDR（卡片上会写「HDR 未开启」）。Windows 设置 → 系统 → 屏幕 → HDR 打开即可。
2. 显示器不支持 HDR（卡片显示「HDR 不支持」）。
3. 该值只影响 SDR 内容的亮度；如果屏幕上现在播放的是 HDR 视频，变化会不明显。

**卡片显示 `--` 或弹出橙色提示？**
说明系统拒绝了读取请求（会附带错误码）。依次尝试：
1. 点「重新检测」；
2. 重启电脑（显卡驱动状态异常时很常见）；
3. 退出安全软件 / 游戏反作弊后重试（少数驱动会拦截显示配置接口）；
4. 点「复制诊断信息」把细节复制出来，便于定位问题。

**亮度过一会儿自己变回去了？**
「设置 → 锁定亮度」在起作用：只要你手动改了亮度（包括在 Windows 设置里改），程序会在检查周期后改回你设定的值。
不想被改回去就取消这个勾选。

**开机自启没生效？**
- 检查「设置 → 开机自启」是否勾选；
- 程序路径被移动过会导致失效（注册表里记录的是绝对路径），重新在设置里勾一次即可；
- 也可以在「任务管理器 → 启动应用」里查看和启停。

**换了接口或用了扩展坞，分组失效了？**
Windows 把「同一个物理显示器通过不同接口」视为不同的显示输出，程序按硬件路径记忆。
重新在下拉框里选一次分组即可。

**程序关不掉？**
点右上角「×」只是收进托盘。彻底退出：托盘图标右键 →「退出」。

**会开机就占资源吗？**
不会。程序常驻时只占 10 MB 左右内存，平时每 20 秒做一次极轻量的状态检查，没有定时任务时几乎不消耗 CPU。

---

## 11. 卸载

1. 托盘图标右键 →「退出」；
2. 「设置」里取消「开机自启」（也可以直接在「任务管理器 → 启动应用」里禁用）；
3. 删除 `HdrBrightness.exe`（和 `hdrbright.exe`）所在文件夹；
4. 可选：删除 `%APPDATA%\HdrBrightness` 目录，清掉配置与定时规则。

卸载不会改变显示器当前亮度，也不会影响 Windows 自己的设置。

## 12. 从源码构建

需要 .NET SDK（或装过 Visual Studio），目标框架 .NET Framework 4.8：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物在 `dist\`：`HdrBrightness.exe`（主程序）与 `hdrbright.exe`（命令行）。

```
src/Shared/             显示配置 API 封装、设置与定时数据模型（主程序与 CLI 共用）
src/HdrBrightness/      WinForms 托盘程序（界面全部自绘）
src/HdrBrightness.Cli/  命令行工具
tools/                  图标生成、底层探针、界面离屏渲染等调试脚本
```
